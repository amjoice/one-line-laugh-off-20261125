One funny line for make.fun's "One-Line Laugh-Off" bounty: a single joke that lands on a cold read, with no setup notes and no explanation. The program writes it to `/output/entry.txt`.

> I told my AI assistant to act more human. It started leaving me on read.

The line was drafted in several versions and sparred head-to-head against the judge's published brief — genuinely funny first, then how hard and suddenly it lands, surprise, economy of words, and freshness — until this version beat the rest.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic, stdlib only, no network.
